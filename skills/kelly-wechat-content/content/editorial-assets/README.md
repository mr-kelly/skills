# 示例素材

`source-checklist.txt` 是整理资料的检查清单。

`screenshots/` 保存本模板在本地 Busabase 实际安装后的运行截图：

- `overview.webp`：工作总览，8 份资料、10 篇文章。
- `board.webp`：只读工作台的文章进度看板。
- `calendar.webp`：只读工作台的 2026 年 10 月发布排期。
- `review.webp`：3 篇待审核稿件和 2 份待核对资料。
- `native-sources.webp`、`native-articles.webp`：Busabase 原生数据表。
- `native-board.webp`、`native-calendar.webp`：补齐视图后的原生看板和日历。

这是虚构编辑团队的演示数据，不代表真实用户统计或已经发布的公众号文章。
素材与业务视图位于不同资源，图片不会替代实际数据表，也不会自动填入记录附件。
