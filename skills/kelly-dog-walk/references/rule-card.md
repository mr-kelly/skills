# 规则卡（Rule Card）

遛狗手册 `SKILL.md` 里给脚本读的小块：一个信息串为 `规则卡` 的代码块。人话规则和规则卡说的是同一件事；
脚本只看规则卡，人只看人话，所以改规则时两边一起改。解析器在
`content/kelly-dog-walk-app/app/js/walk-model.js`（`parseRuleCard`），脚本和遛狗日历用的是同一个。

## 语法

````text
```规则卡
版本: v2
方便时段: 7, 8, 17, 18, 19, 20, 21
默认钟点: 18
换钟点条件: 默认钟点预报降水概率 ≥ 50%
不遛条件: 无
```
````

一行一个 `键: 值`（中文冒号也行），`#` 开头的行是注释。五个键都必须有；多了的键忽略，看不懂的值直接报错——
读了一半的规则卡会悄悄做一件没人写过的事，所以宁可不跑。

| 键 | 值 | 说明 |
| --- | --- | --- |
| 版本 | `v1`、`v2` … | 和手册里的「当前版本」一致，提议时必须往上走 |
| 方便时段 | `7, 8, 17-21` | 可以遛的钟点。分隔符 `,` `，` `、` 都行；范围用 `-` `–` `~` `到` |
| 默认钟点 | `18` | 没有理由换时遛这个钟点；必须在方便时段里 |
| 换钟点条件 | `无` / `总是` / `默认钟点预报降水概率 ≥ N%` | 从不换 / 每天挑最干 / 默认钟点的降水概率到 N 就换 |
| 不遛条件 | `无` / `预报气温 ≥ N°C` | 这样的钟点不遛；方便时段全都这么热时照常按降水概率挑 |

## 怎么选钟点

1. 候选 = 方便时段；有不遛条件时去掉预报气温达标的钟点（全被去掉就保留原样）。
2. `无`：遛默认钟点（默认钟点被热掉了才换）。
3. `默认钟点预报降水概率 ≥ N%`：默认钟点还在候选里、且降水概率 < N，就遛它；否则换。
4. `总是`：每天都换。
5. 换的时候：候选里预报降水概率最低的；一样低挑离默认钟点最近的；还一样挑早的。

这和课程用的 `walk-story.py` 一一对应：`rule_v1` = v1，`rule_v2` = v2，`rule_greedy` = v3，`rule_v3` = v4。

## 课程的四个版本

| 版本 | 方便时段 | 换钟点条件 | 不遛条件 |
| --- | --- | --- | --- |
| v1 | 7, 8, 17–21 | 无 | 无 |
| v2 | 7, 8, 17–21 | 默认钟点预报降水概率 ≥ 50% | 无 |
| v3（坏规则，已退休） | 6–22 | 总是 | 无 |
| v4 | 7, 8, 17–21 | 默认钟点预报降水概率 ≥ 50% | 预报气温 ≥ 32°C |

## 写不出来的规则

规则卡没有「星期几」「月份」「城市」这些键。「周日和周二不遛」这种规则写不进规则卡，也就没法回放、没法有证据——
它只能作为观察写在复盘里。要加新的键，是改这个解析器和裁判的事，由人来做。
