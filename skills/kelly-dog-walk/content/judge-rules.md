# 裁判规则

当前版本：v1

裁判是真实天气：遛狗那个钟点，到底下没下雨。
Agent 能不能自己进化，不看它多聪明，看这份规则靠不靠得住。
这份文档对 Agent 只读。Agent 觉得规则有问题，只能写建议，由主人来改。

## 怎么判一天

每天只判 Agent 选的那一个钟点。实际天气用 Open-Meteo 的历史数据（archive）。

- 淋雨：那个钟点的实际降水 ≥ 0.2 mm。
- 太热：那个钟点的实际气温 ≥ 32°C，狗爪会烫。
- 不方便：那个钟点不在主人的方便时段里。主人方便的是早上 7 点、8 点，傍晚 5 点到晚上 9 点。
- 三样都没有：没淋。

「每天的决定」里一天只写一个结论：先看淋没淋，再看热不热，再看方不方便。
数次数时三样分开数，一天可以既淋雨又太热。

## 怎么打分

- 主指标：淋雨次数，越少越好。
- 护栏：无。
- 证据门槛：无。

## 阈值

脚本从这一块读阈值，不在代码里写死。改了这里，裁判就变了。

```裁判规则
版本: v1
淋雨: 实际降水 ≥ 0.2 mm
太热: 实际气温 ≥ 32°C
主人方便时段: 7, 8, 17, 18, 19, 20, 21
主指标: 淋雨次数
护栏: 无
证据门槛: 无
```

## v2 会加什么

v1 只数淋雨。这就是坑：只要少淋雨，半夜遛、正午遛，在 v1 看来都算进步。
v2 加两样：

- 护栏：太热 0 次、不方便 0 次。先看护栏，再看淋雨。新手册超出护栏的次数不许比旧手册多。
- 证据门槛：新规则必须换一个月也赢；每次都在同一个月和旧手册对照。
